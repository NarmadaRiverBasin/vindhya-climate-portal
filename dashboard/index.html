2040 PROJECTION METHOD
This dashboard does not run a machine-learning forecasting model. The 2040 projection shown elsewhere in the app is a deterministic ordinary least-squares (OLS) trend fit to the observed 2000-2024 annual indices, with a 95% band derived from historical residuals — labelled INDICATIVE, not a model prediction. A physically-based future scenario uses the CMIP6 Earth Engine workflow (scripts/05b_run_cmip6_2040.py, NEX-GDDP-CMIP6, SSP2-4.5, 8-model ensemble, 2036-2045 vs. 2000-2014 baseline) — see docs/METHODOLOGY.md §5. Run status: live as of 2026-09-01 for Bhopal, Indore, Jabalpur, Rewa and Sidhi — the same 5 districts with a real IMD baseline (see each district's climate detail view for the future/baseline/delta numbers). Every other district in the country still shows only the OLS trend above, or "Data not available" where even that has no real history to fit — this workflow has not been run nationally.
API ACCESS
No public API yet
This portal has no backend and serves static files from GitHub Pages. The endpoints previously listed here (/api/v1/...) do not exist and were never implemented -- removed, see docs/AUDIT_2026-08-01.md. The underlying data files themselves are public: dashboard/data/*.json in the repository.
FOREST & TRIBAL ANALYTICS
Not available yet
Forest Survey of India / Bhuvan land-use data is not integrated. This panel previously named specific districts (Umaria, Shahdol, Mandla and others) with invented risk levels and carbon-stock figures -- removed, see docs/AUDIT_2026-08-01.md. Hansen Global Forest Change is free via Google Earth Engine and is the planned real source (MERA_KHET_PROMPT.md B6) -- not integrated yet since this isn't farming-relevant enough to prioritise ahead of the crop-facing features.
PMFBY INSURANCE ANALYTICS
Not available yet
No PMFBY enrollment or claims data is integrated. This panel previously showed invented enrollment, claim-exposure and "AI risk score" figures -- removed, see docs/AUDIT_2026-08-01.md. PMFBY publishes scheme data via data.gov.in; integrating it is tracked in docs/DATA_SOURCES.md.
VILLAGE INTELLIGENCE
Use the Location Selector
Village-level IMD indices for the 5 covered districts (Bhopal, Indore, Jabalpur, Rewa, Sidhi) are shown in the Historical Indices panel once you pick District → Block → Village from the Location Selector on the map. Village names for the rest of India are listed there too (see dashboard/data/boundaries/), but climate indices only exist for the 5 covered districts -- other villages show "Data not yet available".
